Getting started

Install the app, answer three questions on its first launch, and your ComfyUI output folder is a library you can search and remix.

What you need

  • A 64-bit computer running Windows, macOS (Apple silicon or Intel) or Linux.
  • Your own ComfyUI, with the models and custom nodes you use. A Docker install works as well as a native one. WorkflowRemix talks to it over its local address, by default http://127.0.0.1:8188.
  • To be 18 or older, and to agree to the Acceptable Use Policy.

Install it

Get the installer for your system from Downloads.

SystemFileWhat to expect
WindowsWorkflowRemix-Setup-<version>.exeA short wizard asks who it is for and where the program goes. Only for me, the default, needs no administrator rights and keeps updates silent. Until the installer is code-signed, Windows shows Windows protected your PC: choose More info, then Run anyway.
macOSWorkflowRemix-<version>-arm64.dmg for Apple silicon, -x64.dmg for IntelUntil the app is signed and notarized, right-click it and choose Open the first time.
LinuxWorkflowRemix-<version>.AppImageMake it executable with chmod +x, then run it. Some distributions need libfuse2.

The first launch

The app asks its questions itself, the first time it opens, on every system. No server starts until you press Start WorkflowRemix.

  1. Where your data lives. This folder holds your settings, prompts and replacement rules, the job list with the full text of every prompt you run, the logs and, unless you choose otherwise, your media library. For the most privacy, pick a drive your operating system does not index for search, ideally an encrypted one (BitLocker, FileVault or LUKS). The screen says, for each folder you pick, whether it is probably indexed, and warns about a folder that syncs to a cloud service.
  2. Media library (optional). Where favourites and archived media go. Leave it empty to keep the library inside the data folder.
  3. ComfyUI. The address ComfyUI answers on; it does not need to be running yet, and Test checks it if it is. Then, optionally, the ComfyUI folder: the one holding its input, output and user folders (for Docker, the host side of those mounts). That is what lets the app list your workflows and outputs. If your output folder is somewhere else, name it too.
  4. The Acceptable Use Policy. Read it, tick I am 18 or older, and I agree, and press Start.

The data folder is a real decision

It cannot be moved from inside the app afterwards. A search index keeps its own copy of file names and of the text inside files, and that copy outlives the files. If you accept the default, your data goes in your user profile: %LOCALAPPDATA%\WorkflowRemix on Windows, ~/Library/Application Support/WorkflowRemix on macOS, ~/.config/WorkflowRemix on Linux.

A first look round

The home page is five tiles.

MediaThe grid over ComfyUI's output and input folders and everything you have kept. Browsing your media.
JobsRunning and completed runs. Jobs.
WorkflowsThe library Remix runs from. Workflows.
PromptsReusable text for [keyword] rules. The prompt library.
SettingsPaths, privacy, the password and remote access.

Your first remix

  1. Start ComfyUI, if it is not running.
  2. Open Media and switch to Output. Pick a picture ComfyUI made.
  3. Press the bar under its thumbnail to raise Remix. The workflow inside the file is offered as ⤷ Inherit (this image), alongside the workflows in your library.
  4. Change the prompt, and press Run. The job appears in Jobs, and its outputs arrive as thumbnails when each one finishes.

A new install also copies a few starter workflows into your ComfyUI workflows folder and switches them on. They name custom nodes and models you may not have, so read that page before running one.

Finding your data later

File → Show Data Folder opens the folder you chose. Uninstalling the app leaves it in place.
