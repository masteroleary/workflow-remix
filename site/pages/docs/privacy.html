Privacy and security

WorkflowRemix is local first. Your media is served straight off your disk and never leaves the computer, and nothing phones home in the background.

The update check is the one request the app makes without being asked. There is no account, no licence server, no analytics and no automatic crash reporting: a problem report goes only when you choose to send one.

It runs only in its own window

The app is a small server and a window that shows it. The server listens on this computer only and answers nothing but that window: any other program, or a browser pointed at its address, gets a page saying where the app is.

The window itself is held to its own server. Every image, script, font and connection has to come from the app; a link to anywhere else opens in your system browser and not inside the window.

Where your data lives

In the one folder you chose on the first launch: settings, prompts, rules, the job list with every prompt it ran, logs and, unless you put it elsewhere, the media library. File → Show Data Folder opens it.

  • A folder the app creates is made private to your account.
  • To back it up, copy the folder while the app is closed. The settings file in it holds your API keys and your password's hash, so treat a backup as you would the original.
  • Uninstalling leaves the folder in place. Deleting it is how you remove everything.

System search

A library that Windows Search or Spotlight indexes is one whose file names can turn up in the Start menu or in Spotlight for anyone at the desk. Under Settings → Config → Paths the app says, for each folder it keeps things in, whether the system indexes it, and names the system setting that excludes it. It only reads; it changes nothing about what is indexed.

A password for the app

Settings → Security. With a password set and Require a password ticked, the whole app sits behind a lock screen: pages, files, thumbnails and the live connection to ComfyUI alike.

  • At least 7 characters; 12 if you use remote access.
  • Only a salted hash is stored, never the password.
  • Changing it, removing it or switching protection off needs the current password. Being signed in is not enough.
  • Sign out every device ends every session at once without a new password. It is the button for a lost phone, and can be pressed only at the computer.

Forgotten it? Close the app, open config.json in your data folder, remove the auth entry and start the app again.

Secure wipe and the panic password

Settings → Secure wipe. A private library should be yours to remove without a backup utility or a command line. Secure wipe empties the app's own folders — the media library, ComfyUI's input, output and cache, and the app's prompts, rules, saved workflows and index — in the app itself, with no admin rights and no scheduled task. It is off until you turn it on.

  • You choose what goes. Tick the folders to empty. Add the app's own data, and your settings with it if you want the app to forget how it was set up. Leave a backup folder and the app copies everything into a dated folder first; leave it empty to erase with no backup.
  • It refuses to reach past its own data. It empties only the folders you configured, and will not empty a system folder or a drive root even if one is pointed there by mistake — every folder is re-checked at the moment of deletion.
  • Windows' own trail, if you ask. A tick clears the Recent-files list and the jump lists Windows keeps. Cached thumbnails are left to Windows' own Disk Cleanup (tick Thumbnails): the app will not close Explorer to get at them, on purpose.

The panic password is the same wipe, armed on the lock screen. Set a second password under Settings → Security and typing it does not unlock the app — it erases everything, instantly, with no confirmation and no backup. If you are ever made to open the app, it opens onto nothing. It fires only once secure wipe is on, and the lock screen cannot tell it apart from a wrong password.

Before you sell or hand on the computer

Wiping the app's data clears what WorkflowRemix made. For the whole machine, let the operating system do the rest — the app never reaches that far itself:

  • Turn on drive encryption — BitLocker on Windows, FileVault on a Mac — so the disk is unreadable without your key if the computer is lost, sold or taken.
  • Clear cached thumbnails with Windows' Disk Cleanup, ticking Thumbnails.
  • Reset the machine when it changes hands: on Windows, Settings → System → Recovery → Reset this PC → Remove everything with Clean the drive on; a Mac erases from Recovery.

WorkflowRemix does none of these for you. They belong to the operating system, and an ordinary app that reached for shadow copies, event logs or free space would behave like the software your antivirus is built to stop — which is exactly what this app is built not to be.

Safe mode

The eye in the browse bar hides any file whose prompt matches a word on your filter list, from listings and from the word directory. It is for a shared screen, or someone looking over your shoulder.

  • The list is yours, under Settings → Privacy, and starts with only a few generic words.
  • Matching ignores case and sees through digit-for-letter spellings, which model and LoRA file names use on purpose.
  • A video and the still beside it are one item: if either is flagged, both are hidden.
  • On a device using remote access, safe mode is held on by the computer and the list itself is never shown there, unless you tick Show flagged media on remote devices at the computer.

It is a filter on prompt words, not an image classifier. It hides what the words in a file's prompt match, and knows nothing about a file with no prompt in it.

Media caching

Settings → Privacy → Media caching decides whether thumbnails and media the window has already loaded may be kept on disk for reuse. The default is never. Signing out clears what was kept.

The built-in safeguard

Every run is read before it reaches ComfyUI, whichever screen or device it came from.

  • A run that describes a minor sexually is refused. A few words are refused wherever they appear. An age under 18, or a word such as “teen” or “high school”, is refused when a sexual word is present as well. The names of the models and LoRAs are read as well as the prompt, and a word on your own safe-mode list counts as a sexual word too.
  • An ordinary picture of a child, or of a school, runs. So does an ordinary adult prompt.
  • Every run that goes on gets a few words added to its negative prompt: age words, or, where the prompt names a minor, sexual words. A file therefore records a negative prompt slightly longer than the one you typed.
  • Nothing switches it off. There is no setting for it.

A refused run tells you which words it was refused for. If the prompt was about an adult, say so plainly (“a woman in her thirties”) and drop the word that reads otherwise.

It is a word check and not an image classifier: it stops the run that asks, and cannot see what a model draws unasked. What you make remains your responsibility under the Acceptable Use Policy.
