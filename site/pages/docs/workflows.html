Workflows and models

The Workflows page is what Remix runs from: the workflows that come with the app, and any in your ComfyUI's own folder, each checked against your install before it is offered.

Watch a workflow checked and run in one click.

Check it, then run it

A workflow that has not been checked wears an Enable button. Press it and the app works out everything the workflow needs, every custom node, checkpoint, LoRA, VAE and text encoder, and ticks each one off against your ComfyUI. Adding a workflow with + starts the same check.

  • Everything found: it is offered in Remix, and a big Run runs it once on its own settings, with the sample pictures that ship with the app where it takes one. The sheet says first what Run will do.
  • Something missing: the sheet lists the missing nodes, and the missing files under the folder each belongs in. Beside each file, Download where the app knows where it comes from, and Find manually to pick a file you already have. Copy Agent ToolCall copies exact install steps, node packs, versions, file paths and links, for you or an AI coding agent to follow.
  • Checked against your ComfyUI as it is now. Move or update ComfyUI and Recheck all workflows in Settings goes through them again. A node pack that failed to load is told apart from one that is missing.

Downloads, substitutes and notes

  • Download fetches a model straight into the right folder, from Hugging Face or Civitai only, checked by its size and fingerprint. A gated model needs your free Hugging Face token, and Civitai your API key, both kept in Settings and sent nowhere else.
  • Find manually takes a file you already have under another name: it becomes a substitute, used for that model in every workflow from then on (Settings → Model substitutes).
  • Your models and LoRAs (Settings) is where you describe your own files: what each is for, its tags, its recommended strength and settings, notes for the AI. Studios and the AI agent choose and set LoRAs by them.
  • Recommended models, under Settings → NSFW and only if you switch it on, lists models we recommend for adult work, with their notes and tags, and copies a request to fetch the ones you tick.

What comes with the app

How a form is made

There is nothing to map by hand. The app reads the graph, asks ComfyUI what each node's settings are, and offers the ones that can reach the output: a prompt box, a seed, a model picker, a LoRA stack, a picture box. It knows a muted branch from a live one, an optional second picture from a required one, and an edit instruction from a description. When it gets a role wrong, Remix fields on the Workflows page corrects it, with Undo.

Putting the starters back

Settings → Restore defaults puts back what a new install starts with, part by part: the keywords, the prompt library, the bundled workflows. A bundled workflow you changed is kept beside itself as .bak. The app asks before it writes anything, and only from the computer it runs on.
