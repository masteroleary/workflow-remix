Browsing your media

Media opens a grid over everything you have: images, video and audio, by folder.

Where it looks

The folder name at the top opens Library, which moves between the places the app knows about:

  • Output, fresh from the queue: ComfyUI's own output folder, so a render shows up without being copied anywhere.
  • Input, what runs are fed from: ComfyUI's input folder.
  • Favorites, everything you kept: the media library you chose at setup.

The chips under the search box sort by date or name (Sort), choose the layout, the tile size and how many items a page holds (View), and filter by type or flatten every subfolder into one grid (Filters). Folders are cards above the pictures. The page comes back to where you were when you return from the viewer.

Search by name, or by prompt

A background index reads the prompt written inside each generated file. So a search for “ocean” finds every picture whose prompt mentioned it, whatever the file is called. Search can also go down into every subfolder, and groups what it finds under the folders they are in.

The index is built shortly after the app starts and refreshed every ten minutes. A file rendered a moment ago is found by name at once, and by prompt after the next refresh.

The word directory

Every word and phrase used across your prompts, sorted by how often it appears or from A to Z. Pick one to see every file that used it.

What a tile tells you

Each tile is a square thumbnail with a bar under it.

  • The thumbnail opens the viewer.
  • The bar raises Remix for that file.
  • A wf tag means the file carries a workflow.
  • A kw tag means the file is still a template: the prompt it was written from holds [keywords] you have rules for, so remixing it will answer them again. Hover the tag to see which.

A video and the still image saved beside it under the same name are one item. They are listed, moved and deleted together.

The viewer

Full screen, with swipe or the arrows to move through the folder, and a slideshow whose speed you set. Video plays in the page. From here you can open the file's inspect page, which shows everything written into it and has the same Remix form in tabs: Workflow, Run and Preview.

Keeping and removing

  • Favorite moves a file into your library, which is how a render becomes a kept file. A file that is already in the library goes into its _Favorites folder.
  • Delete removes the file from disk, with its thumbnail.
  • Multi-select does either to many files at once.

Delete means delete

The file is removed from the folder it is in, not hidden. The app's delete buttons reach every folder listed above, ComfyUI's own included.

On a shared screen

  • Blur (a chip in the bar, and a button in the viewer) blurs every thumbnail and the picture open in the viewer, so the library can be browsed without showing what is in it. It comes back on by itself whenever the app goes out of sight, so returning to it shows nothing at a glance; each device can switch that off under Settings → Privacy.
  • Safe mode (the eye) leaves out any file whose prompt matches a word on your own filter list. It is on when you first open the app. The list is yours to fill in under Settings → Privacy. More about safe mode.
