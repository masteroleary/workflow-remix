Remix

Remix turns a workflow into a form, fills it from the file you opened, and queues what you changed on your ComfyUI. Change one thing and run it again, or send the picture through a different workflow.

Watch it used: a picture edited with words, one prompt on two models, and someone swapped into a video.

Open Remix from the bar under any tile, or from the viewer. It goes in three tabs: Workflow (which workflow, and its form), Keywords (keywords and collections) and Run. Next walks through them and skips Keywords when the prompt has none. Back or Esc returns you to wherever you came from.

Which workflow runs

  • Inherit: the exact workflow written into the file.
  • A workflow from your library, with the file's own picture fed in. This is how a picture made one way goes through a different model, an edit or an image-to-video workflow. Switching asks whether to keep the prompt in the box or take the new workflow's, except for an edit workflow, whose prompt is an instruction.
  • Shortcuts: a workflow saved with the values on screen, listed under it.

Remix reads ComfyUI's own templates as well as the workflows that come with the app: Flux, Qwen Image Edit, Z-Image, Wan, MiniMax H3 and LTX among them.

The form

The app reads the graph and works out which of its settings are worth a control, then lays them out by what they are for, not by node: the prompt and negative prompt, the picture, video and audio boxes, the model, a Generation card (seed, steps, guidance, denoise, Turbo), a size card, and everything else under Other settings. What it found and left out is in the hidden fields list. A setting that cannot reach the render is not offered at all.

  • Seed: a die means a fresh seed every run; type a number and press Lock to repeat a run. ↺ this file's seed puts back the one the file was made with.
  • Size: a Resolution list of the sizes the model works well at, and Match Input Image, which sizes each run to the picture going in. A video workflow with a guide video has Use reference video length.
  • Models: pick more than one and a run is queued once per model, model by model, on shared seeds. A model your ComfyUI does not list shows in amber.
  • LoRAs: a search over every LoRA your ComfyUI lists, with its family marked. A high and low pair counts as one.
  • Pictures: the main image box holds the file you are remixing. Browse picks something else from your library; pick several and each is a job of its own.
  • AI beside the prompt opens the agent in a panel, to rewrite the prompt with you in the format the model reads best.

A file made from a prompt with [keywords] in it remembers both versions: Keyword Prompt gives you the template to answer afresh, Remix Prompt the finished text.

Running

The Run button says how many jobs one press queues:

models picked  ×  files picked  ×  prompt variations ticked

Each job renders the run count you set, and the outputs land on the Run tab as each finishes, newest press first, so you can compare. Every job is on the Jobs page whether or not you stay. ComfyUI has to be running; if it is not, the app says so and, where it can, offers to start it.

Every run is checked first

Before a run reaches ComfyUI, the built-in safeguard reads it and refuses one that describes a minor sexually. Every other run reaches ComfyUI exactly as you built it. How the safeguard works.

Back to ComfyUI

The workflow written into every file the app makes is exactly the one that ran, so a picture dragged back into ComfyUI makes the same picture. Two buttons on a file:

  • Open in ComfyUI saves the file's workflow, as it ran, among ComfyUI's workflows, ready to open there.
  • Save as workflow adds it to your library, where it goes through the requirements check and comes back to Remix.

Making a change stick
