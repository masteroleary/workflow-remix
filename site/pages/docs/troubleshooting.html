Troubleshooting

The things that go wrong most often, and what each one means.

Installing

Windows says it protected my PC

The installer is not code-signed yet. Choose More info, then Run anyway.

macOS will not open it

The app is not signed and notarized yet. Right-click it and choose Open the first time.

The Linux AppImage does nothing

Make it executable (chmod +x). Some distributions also need libfuse2 installed.

The app says its data folder is gone

The folder you chose is on a drive that is not connected. The app offers Try again, Choose another folder and Quit, and never starts fresh on its own. Reconnect the drive and try again.

ComfyUI

Runs do not start

ComfyUI is not answering at the address in Settings → Config. Start it, or correct the address. Where the app can find ComfyUI's launcher it offers to start it for you.

A job fails as soon as it is queued

Read the job's log. ComfyUI's own reason is in it, and it is nearly always a model, LoRA or custom node the workflow names that your install does not have. A model pill shown in amber is the app telling you the same thing before you run.

The form takes a while to appear

To build a form the app asks ComfyUI to describe every node it has installed, and a ComfyUI with many custom nodes takes a moment to answer, most of all just after it has started. The answer is reused afterwards.

A setting I expected is not in the form

Look in the hidden fields list under the form. A setting on a muted or bypassed node is listed there as asleep. One that cannot reach the output at all is left out, with a note saying what went and why; rewire the workflow in ComfyUI and it comes back.

My workflow list is empty

The app lists the workflows folder inside the ComfyUI folder you gave it. Check that folder under Settings → Config; for a Docker install it is the host side of the mounts.

Runs

A run was refused

The built-in safeguard read the run as describing a minor sexually, and the message names the words. If the prompt was about an adult, say so plainly and remove the word that reads otherwise. A model or LoRA file name can be the cause as well as the prompt.

One click queued far more jobs than I meant

Several answers ticked for a keyword multiply the run, and so do several models. The summary line of the Prompt Replacements panel states the total before you press Run; untick prompts in its preview to bring it down. Cancel on a job stops it in ComfyUI's queue.

The seed box is empty

That means random, a new seed each run. Pin a number to repeat a result, or press ↺ this file's seed.

A new file is not found by its prompt

The prompt index is refreshed every ten minutes. Until then the file is found by name.

The app itself

I opened the app's address in a browser and got a notice

By design. The app answers only its own window. To use it from another device, switch on remote access.

I forgot the password

Close the app, open config.json in your data folder, remove the auth entry and start the app again.

Where are the logs?

In your data folder: File → Show Data Folder.

Reporting a problem

Press Report on an error message or a failed job, or choose Settings → Report a problem. The app puts together a report for support and shows you every part of it before anything is sent:

  • This device: the system, processor, memory and graphics card, and the versions of ComfyUI, Python, PyTorch and the custom node packs, set beside the versions the app's own workflows are tested with.
  • The app's log and ComfyUI's log.
  • What went wrong, and a note of your own if you add one.

Untick any part you would rather keep. Your folders, file names, account and computer names, addresses and keys are taken out first, and so is your prompt text unless you tick to include it. Press Send and you get a report ID, like WR-7K3F9Q2M, to pass on to support. Reports are deleted after 30 days.

Remote access

The address does not answer

  • The desktop app has to be open on the computer.
  • The phone has to be on your tailnet: the Tailscale app connected and signed in with your account.
  • The computer's Tailscale key may have expired. The Remote access page warns for a month beforehand.

The phone is turned away before the password

Either the phone is signed in to Tailscale with a different account while Only my Tailscale account is on, or the phone is a tagged device, which carries no account. Sign in with your own account and do not tag the phone.

The phone keeps being asked to sign in

A remote session lasts 8 hours without use, and a week at most. That is deliberate.

Everything in Settings is greyed out on the phone

Settings are changed at the computer. A phone can read them.
