Keywords and collections

Write a prompt once with [keywords] in it, and choose what each keyword means from a library of text you keep. One prompt becomes as many as you tick, and a collection answers it from another world.

Watch it done: variations from keywords, and one prompt answered by four collections.

The three pieces

  • The library, on the Prompts page: rows of reusable text, filed on shelves. A shelf is a keyword: the Scene shelf is what [scene] is answered from. Each row can carry a negative prompt of its own.
  • The rules, on the Keywords tab of Remix and of a workflow's own page: each keyword with the answers ticked for it, and plain find → replace pairs. They are the app's, not a workflow's, so they apply to whatever you run.
  • The collection, a menu at the top of that tab: which set of shelves answers.

Several answers are several jobs

Tick three answers for [character] and a run queues three jobs, one per answer. Tick two for [scene] as well and it is six: every combination. The tab's summary does the arithmetic before you press Run, and counts only the keywords this prompt can reach.

Under the rows, the tab shows every prompt the run will send, in full. Each has a tick box: untick a prompt and that job is never queued, so twenty-seven combinations of which you wanted five is five ticks. A keyword can hold another: a hairstyle row that says [haircolor] brings that keyword in with it.

Negatives that travel with their answer

A library row's negative prompt goes into the workflow's negative prompt whenever that answer is used, so a style and the things it should avoid are one choice and one job. The preview shows each prompt's negative under it.

Two answers in one picture

To put two answers from the same shelf in one picture, address them by position, counting from 0: [character][0] sits across the table from [character][1]. The ＋ on a previewed prompt saves that whole finished paragraph as a capture, [prompt1], so two fully described figures can share a picture: [prompt1] stands beside [prompt2].

Collections

A new install has six: General, Fantasy World, Cyberpunk, Futuristic Space, Logo Design and WaiSnackMix, a model's own style presets with the negative prompt each one goes with (watch them style one picture three ways). Choosing one in the Collection menu decides where every keyword is answered from. So one prompt:

[style], [character], [expression], [action], [scene], [lighting]

is a wizard in an enchanted forest in one collection and a robot in a rocket ship in the next, with no rule edited. In Logo Design the same [showcase] becomes a logo in three styles.

  • The shelves are shared. [scene] means the Scene shelf whichever collection is answering. What differs is the rows on it.
  • General is the fall back. A keyword the chosen collection has no shelf for is answered from General's, and the row says so.
  • Each collection keeps its own ticks, and which collection is selected is this device's own.

The Prompts page shows one collection at a time. Add, rename or remove a collection there; under its own shelves, a line lists the keywords it borrows from General, each with a ＋ to start a shelf of its own. Removing a collection removes its rows and the rules ticked from them, after a confirmation that counts both. Settings → Restore defaults puts the starter collections back as they shipped.

Good habits

  • Keep rows free of pronouns. “Holding a lantern” reads right after any character; “she holds a lantern” does not.
  • Give every collection the same shelves if you want one prompt to work in all of them.
  • Watch the count. Three keywords with three answers each is 27 jobs.
