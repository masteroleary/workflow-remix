The prompt library

Write a prompt once with [keywords] in it, and choose what each keyword means from a library of text you keep. One prompt becomes as many as you tick.

The three pieces

  • The library, on the Prompts page: rows of reusable text, filed on shelves. A shelf is a keyword. The Scene shelf is what [scene] is answered from.
  • The rules, in the Prompt Replacements panel, on the Remix page's Keywords tab (on the inspect page, at the foot of its Run tab): a list of find → replace pairs applied to the prompt just before a run is queued.
  • The collection, a drop-down at the top of that panel: which set of shelves answers.

The rules are stored by the app, not in a workflow, so they apply to whatever you run.

Rules

A rule's find is either plain text or a keyword in square brackets.

  • Plain text is replaced with what you type: blonde → platinum.
  • A [keyword] is answered from the library. Its value cell opens a tick list over the shelf the keyword names, so you pick answers, you do not type them.

Keywords are answered first, and plain-text rules then run over the finished text. So blonde → platinum also catches a “blonde” that arrived inside a library row.

When you reach the panel, any [keyword] your prompt uses and no rule answers gets an empty row of its own, so a keyword is never silently swept out of a run.

Several answers are several jobs

Tick three answers for [character] and a run queues three jobs, one per answer. Tick two for [scene] as well and it is six: every combination.

The panel's summary line does the arithmetic before you press Run:

Prompt Replacements — 9 active, 3 ignored, 12 jobs total
  • Active rules will change this run.
  • Ignored rules are switched on but cannot fire, because this prompt never mentions their keyword. They multiply nothing. Hover the number to see which.
  • Jobs total is what one click queues, with the models and files you picked counted in.

Read every prompt before it runs

Open the panel and it shows each prompt the run will send, in full, with every replaced stretch painted in the colour of the rule that put it there. Each one has a tick box: untick a prompt and that job is never queued. Twenty-seven combinations of which you wanted five is five ticks.

Two answers in one picture

Variations are “one of these per job”. To put two answers from the same shelf in one picture, address them by position, counting from 0:

[character][0] sits across the table from [character][1]

Using an index anywhere stops that keyword multiplying the run: every answer rides along, and each reference takes its own. The tick list shows each answer's number.

Captures

The ＋ on a previewed prompt saves that whole finished paragraph to the library, on a shelf called Captured, and adds a rule [prompt1] pointing at it (then [prompt2], and so on). A capture is taken after every keyword in it was answered, so it stays as it is: it does not vary and costs no extra jobs.

That is how two different, fully described figures share one picture: [prompt1] stands beside [prompt2]. While a capture is in use, the rules it was made from are switched off and folded away, and come back when it leaves the prompt.

A [promptN] row can also be built by hand. Its answers are then parts joined into one description (a character, a hair style, an outfit), not alternatives. Only two answers from the same shelf count as variations.

Collections

The library is filed in collections. A new install has five: General, Fantasy World, Cyberpunk, Futuristic Space and Logo Design. Choosing one in the Collection drop-down decides where every keyword is answered from. So one prompt:

[style], [character], [expression], [action], [scene], [lighting]

is a robot in a rocket ship in one collection and a wizard in an enchanted forest in the next, with no rule edited. The starter collections shows all of them, Logo Design among them, whose own Showcase row turns the same [showcase] into a logo.

  • The shelves are shared. [scene] means the Scene shelf whichever collection is answering. What differs is the rows on it.
  • General is the fall back. A keyword the chosen collection has no shelf for is answered from General's, and the row says so with a General tag.
  • A shelf with nothing ticked stays unanswered. If the collection has the shelf but you have ticked nothing on it, the keyword is left empty. It does not quietly borrow General's answer.
  • Ticks belong to their collection. Each collection remembers its own answers, so switching back finds them as you left them.
  • The choice is per device. The rules are shared; which collection is selected is this window's own.

Managing them

The Prompts page shows one collection at a time, as tabs. Add one with ＋ Collection, rename it, or remove it. Under a collection's own shelves, a line lists the keywords it borrows from General, each with a ＋ that starts a shelf of its own for that keyword.

Removing a collection removes its rows

Its prompts and the rules ticked from them go with it, after a confirmation that counts both. General can be neither renamed nor removed.

Good habits

  • Keep rows free of pronouns where you can. “Holding a lantern” reads right after any character; “she holds a lantern” does not.
  • Give every collection the same shelves if you want one prompt to work in all of them, and leave out the ones that should be shared.
  • Watch the jobs total. Three keywords with three answers each is 27 jobs.
