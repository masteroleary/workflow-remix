The WorkflowRemix desktop app for Windows 10 and 11. It keeps your data in a folder you choose, and updates itself. Versions for macOS and Linux are on the way.

{{downloads}}

Before you install

  • You need your own ComfyUI. WorkflowRemix does not install ComfyUI or any models. It talks to the one you already run.
  • It is for adults. The app starts only once you confirm you are 18 or older and agree to the Acceptable Use Policy.
  • The installers are not code-signed yet. Windows shows Windows protected your PC: choose More info, then Run anyway.

Getting started walks through the install and the first launch.

Where the files come from

The installers are published as releases at github.com/masteroleary/workflow-remix, which is also where an installed copy looks for updates. The buttons above link straight to the files there; this site reads the release list itself, so your browser contacts GitHub only when you click one.
