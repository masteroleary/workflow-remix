One prompt, four worlds

A collection answers every keyword in a prompt at once. Switch it, and the same prompt is a different world.

The steps

  1. Open the Prompts page to see the collections. Each category is a keyword, each row an answer; a keyword a collection has no shelf for is answered from General.
  2. Open Remix on any picture and replace its prompt with [showcase]. In General, showcase holds six more keywords: a style, a character, an expression, an action, a scene and the lighting.
  3. On the Keywords tab, pick a collection. The preview shows every prompt the run will send, each part in the colour of the keyword that wrote it. Untick any you do not want.
  4. Run it, then switch the collection and run again. The Run tab keeps every picture of the visit, newest first, side by side.
