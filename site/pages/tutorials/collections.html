Keyword collections

A collection answers every keyword in a prompt at once. It can be a whole world, or a model's own style presets.

One prompt, four worlds

Switch the collection between Fantasy World, Cyberpunk, Futuristic Space and Logo Design, and the same prompt is a different world each time, with nothing retyped.

  1. Open the Prompts page to see the collections. Each category is a keyword, each row an answer; a keyword a collection has no shelf for is answered from General.
  2. Open Remix on any picture and replace its prompt with [showcase]. In General, showcase holds six more keywords: a style, a character, an expression, an action, a scene and the lighting.
  3. On the Keywords tab, pick a collection. The preview shows every prompt the run will send, each part in the colour of the keyword that wrote it. Untick any you do not want.
  4. Run it, then switch the collection and run again. The Run tab keeps every picture of the visit, newest first, side by side.

A model's style presets

WaiSnackMix is a different kind of collection: one shelf, Quality, holding an anime model's style presets. Each is a line of quality words with a negative prompt of its own, and Anima Turbo, the anime workflow that ships with the app, starts its prompt with the keyword they answer.

  1. Open the Prompts page and pick WaiSnackMix. Each preset shows its quality words and, beside them, its negative prompt.
  2. Open Remix on any picture and switch the workflow to Anima Turbo (add it from the Workflows page's + first). Write the prompt with [quality] at the start, then the subject.
  3. Lock a seed, so every style starts from the same noise and only the style changes.
  4. On the Keywords tab, pick WaiSnackMix. Quality is answered with Realism, as it ships, and the preview shows its negative under the prompt. Tick more presets on the quality row: each one is a job of its own, with its own negative written into the workflow's negative prompt.
  5. Run them, and lay the pictures side by side with View → Mason.
