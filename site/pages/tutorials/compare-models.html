Compare models side by side

Run one prompt on several models at once and see what each one makes. Every model gets the same seeds, so what changes from one picture to the next is the model, not the noise.

The steps

  1. In Media, open Remix on a picture and pick a workflow in the Workflow menu. The picture's prompt comes with it. The video uses Anima Turbo, which you add from the + on the Workflows page.
  2. The Model box shows the model the workflow loads, marked in workflow. Search for another and pick it: the first pick replaces it.
  3. Every pick after that adds a model, and each job runs once on each of them. Pick the in-workflow model back to keep it beside the rest.
  4. Models from different families get a warning, such as Anima and WAN: the LoRAs, VAE and text encoder are set up for one family, and fail or do nothing on another.
  5. Pick a size from the Resolution list, which offers the sizes the first picked model works well at, then choose how many runs each job makes on the Run tab.
  6. Press Run. The models are queued one after another, so each loads once, and the pictures appear side by side.

More on the model box, seeds and how many jobs a run queues is in Remixing a file.
