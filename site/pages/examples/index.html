What a new install comes with, written out, so you can see how the pieces fit before you build your own.

  • {{icon:graph-outline}}Starter workflowsThe six workflows that come with the app: what each makes, with a before and after, and what it needs.
  • {{icon:bookshelf}}Starter collectionsFive prompt collections, and one prompt answered by each of them: four scenes and a logo.
  • {{icon:lightbulb-on-outline}}Prompt recipesShort patterns for variations, two figures in one picture, and model comparisons.

These are starting points

The workflows name the models and custom nodes their author used, and the collections are deliberately small. The collections are written into your own install once, on first run, and are yours to change from then on. The workflows run from the app itself, and an edit you save to one is kept in your media folder.
